# PERSONAS — who it's for

## 1. The solo AI-assisted builder
Runs a coding agent (Claude Code, Cursor, Codex, …) to build real software. Wants disciplined,
multi-session progress without re-explaining context each session, and self-verification so the
agent doesn't declare fake victories. Hires the harness to be the agent's memory + guardrails.

## 2. The multi-tool team
Different people use different agents — one on Claude, one on Copilot, one on Gemini/Antigravity,
one in Cursor. Wants **one** shared operating contract, not N drifting instruction files. Hires
the LLM-agnostic entry points so every tool obeys the same rules from the same file.

## 3. The adopter
Has an existing codebase and wants the harness's discipline without a rewrite. Hires **Adopt
mode**: point the harness at the repo, let it read the code, reconstruct the roadmap, codify the
boundaries the code already follows, and continue building from the next real increment.

Kept short on purpose — this file exists to settle scope arguments, not to be comprehensive.
